Triagem e atendimento com IA

Duas partes do mesmo projeto. A triagem lê o chamado, esconde os dados pessoais e escolhe a fila. O atendimento responde o lojista com a base de ajuda e chama uma pessoa quando precisa.

Ver o código no GitHub Documentação da API

Chamado

Cole a mensagem de um cliente. A API esconde os dados pessoais, classifica com IA e diz para qual fila o chamado vai.
